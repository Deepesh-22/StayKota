# Kota map scope and circular previews

`src/lib/map-area.ts` defines a configurable urban envelope (`75.75,25.08` to `75.94,25.26`, longitude/latitude) and a 3 km spherical buffer. This is an approximate product navigation area, not an official Kota municipal boundary. Replace the footprint with reviewed municipal geometry if legal or administrative accuracy is required. Rounded corner arcs avoid extending the diagonal buffer to approximately 4.2 km.

The shared MapLibre instance uses enclosing maximum bounds, a minimum zoom recalculated from each viewport and a rounded-area camera-centre correction. A polygon mask hides map scenery outside the area, and building extrusions use a within-area filter. Satellite imagery, clustering, search targets, live location and compact maps keep the same instance and limits. Outside GPS or selected coordinates are explained; pins are not moved to fake in-area coordinates. Existing listing details stay available. Search-radius filters continue to mean distance from a campus or student, separately from the geographic navigation window.

The native +/− and compass buttons are enlarged to 46 px. The new range slider works with pointer, touch and keyboard and shows the current zoom level. Reset Kota view resets the camera without clearing selected room or hostel filters. Its minimum updates after desktop/mobile resize; the resize observer sets the new minimum before notifying map listeners.

`HoverMapPin` adds preview state around the existing marker button. `MapCirclePreview` is a 164 px navy ring, curved white uppercase Manrope labels, separator dots and a photo or transparent pin centre. Long labels split across arcs and retain their full accessible name. Native titles are omitted to avoid a competing tooltip. The expanded circle has a stable pointer hit area, is shifted inside the map edges, and remains below actual map controls. Hover/focus only previews. Click/tap on a hostel opens its public preview page; campus clicks retain centring. The preview links to the full detail route, which requires demo login. Returning to the map preserves the source filters and selected hostel. A separate Clear selection control replaces the old bottom strip’s close action. Escape, leave, blur and map movement dismiss it. SVG path IDs are unique and reduced motion is supported.

Verification: unit checks for spherical padding, diagonal corners, service-area membership, viewport-dependent zoom limits and existing map logic; browser checks for actual camera bounds, zoom buttons/slider, outside GPS, resize, ring dimensions and accessible names, pointer transfer, Escape, hover without selection, click selection and retained room links. Existing satellite, 3D, location, mobile, card and gallery regression checks pass. Production smoke testing also exercised the 3D map after mobile resize without runtime errors or horizontal overflow.

The small PNG crops show the real preview component against an explicitly stubbed style background. They do not claim live tile coverage. Current seed hostel/campus locations and photos remain demo content; no locations, pages or provider basemaps were replaced with placeholders.
